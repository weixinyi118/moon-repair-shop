# 月亮修理铺 · The Moon Repair Shop

一件可以旋转和触摸的 Three.js 微缩机械藏品。月面、房屋、悬浮陨石、玻璃瓶和云海都在浏览器中生成。

[在线体验](https://glittery-fudge-75fa24.netlify.app/)

## 运行

在本目录启动静态服务，然后打开 [月亮修理铺](http://127.0.0.1:8765/)。需要支持 WebGL 2 的浏览器。

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

Three.js、OrbitControls 和 Instrument Serif 字体随站点提供。无需安装依赖或构建。

## 操作

- 鼠标拖拽或单指滑动旋转，右键拖拽平移，滚轮或双指捏合缩放。
- 点击月亮或 **Mend the moon**。齿轮归位，金色星光沿裂缝合拢。
- 点击发光星星，或按 **Stardust** 收集下一颗星。星星飞入右侧玻璃瓶，瓶内会留下光粒。
- 点击门或 **Look inside** 近看橱窗里的星仪。点 **Back to orbit** 或按 Esc 回到默认镜头。
- 右上角切换昼夜、环境声和重置镜头。环境声默认关闭。

## 源码

- `main.js` 管理渲染、镜头、点选和界面状态。
- `moon.js` 生成分段月壳、琉璃镶边、蚀刻纹理、星环和修复动画。
- `shop.js` 生成悬浮陨石、房屋、机械与橱窗。
- `sky.js` 生成云海着色器、星星、瓶子及收集动画。
- `craft.js` 提供共享材质、几何、反射环境与静态实例化，`sound.js` 用 Web Audio 合成环境声。

场景限制渲染像素数，静态灯光阴影使用缓存。系统开启「减少动态效果」时，场景停止环境漂浮，保留主要交互。
